# Land Clearing Charlotte & Site Prep

Lead-generation and silo-structured web platform for **Land Clearing Charlotte**, providing heavy-duty forestry mulching, acreage clearing, lot clearing, and commercial site prep across Charlotte, NC and surrounding areas.

---

## 📁 Repository Structure

- **`charlotte-land-clearing/`**: The complete production multi-page silo website containing over 20 localized service pages, canonical styling (`style.css`), service styling (`service-page.css`), and interactive quote scripting (`site.js`).
- **`docs/`**: Comprehensive content silo architectures, prompt templates, and SEO keyword mapping.
- **`images/`**: High-resolution photography assets from local North Carolina land clearing job sites.

---

## 🚀 Quick Start

To preview the main site locally, open `charlotte-land-clearing/index.html` in any browser or run a simple local web server:

```powershell
# Using Python
python -m http.server 8000 --directory charlotte-land-clearing

# Using Node / npx
npx serve charlotte-land-clearing
```
